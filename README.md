# CodSoft
🌐 Multi-Project Web Development Repository

Welcome to this repository showcasing a trio of frontend web development projects. Each branch contains a unique application that demonstrates different aspects of modern web design and interactivity. Whether you're here to view a  portfolio, explore a functional calculator, or get inspired by a travel website concept — you're in the right place!

---

📌 Repository Structure

This repository contains 3 project:

---

🔹 1. `portfolio-project` — Personal Developer Portfolio 💼

A clean, responsive, and modern portfolio website crafted to highlight your skills, experience, and projects as a developer.

Key Features:

- Professional layout and aesthetic
- Hero section with personal introduction and call-to-action
- Skills, Projects, and About sections
- Contact form with form validation
- Fully responsive and mobile-friendly
- Smooth scrolling and animated transitions

Technologies Used:  
`HTML5`, `CSS3`, `JavaScript`

Purpose:
Perfect for showcasing your work to potential employers or clients in a clean, easy-to-navigate format.

---

🔹 2. `calculator-project` — Functional Calculator App 🧮

A simple yet powerful web-based calculator built using JavaScript. Designed to replicate the behavior of a standard calculator, it’s a great demonstration of DOM manipulation and user interaction.

Key Features:

- Performs basic arithmetic operations (addition, subtraction, multiplication, division)
- Real-time input display
- Clear/reset button for user convenience
- Keyboard input support
- Responsive design for various screen sizes

Technologies Used: 
`HTML`, `CSS`, `JavaScript`

Purpose:  
An excellent project to illustrate core JavaScript logic and event-driven programming.

---

🔹 3. `travel-landing-page` — Travel Website Landing Page 🌍

A visually engaging landing page for a fictional travel company. Built to capture the imagination of potential customers and encourage them to explore destinations around the world.

Key Features:

- High-quality hero image with overlay text
- Destination highlights and promotional sections
- Eye-catching CTAs (Call-to-Action)
- Smooth animations and scroll effects
- Optimized for mobile and desktop devices

Technologies Used: 
`HTML5`, `CSS3`, `JavaScript`
